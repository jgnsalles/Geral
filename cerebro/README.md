# Cérebro: cópia de segurança

- `app/`: cópia de tudo o que o app publicado em cerebro-joao.jgnsalles.workers.dev serve: código (index.html, app.js, estilo.css, sw.js), dados (grade, séries, caixa, eventos, inscrições, novidades), resumos, transcrições e acervo de episódios.
- `HISTORICO.md`: o histórico em texto (notas, podcasts salvos, ouvidos e removidos, resumos, Caixa e séries).
- `scripts/historico.py`: gera o HISTORICO.md de novo a partir de `app/dados`.

A fonte original fica em jgnsalles/Claude-Code (o app sincroniza em `cerebro/registro` ali). Esta pasta é uma cópia de leitura tirada em 2026-11-07.
